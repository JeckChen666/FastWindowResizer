# FastWindowResizer v1.0.0

首个公开版本：通过托盘菜单将屏幕外、异常缩小或最小化的应用窗口找回到眼前，适合远程办公、分辨率变化和显示器切换后手动恢复窗口。

## 功能

- 右键托盘图标显示接近 Alt+Tab 的应用窗口列表。
- 点击窗口后还原并居中到鼠标所在屏幕，必要时修正异常尺寸。
- 同一应用多个独立窗口分别显示，支持固定尺寸窗口及活动模态对话框。
- 提供当前用户范围的“开机自启”开关，默认关闭。
- 单实例运行，无快捷键依赖、后台轮询或联网功能。
- 蓝白图标包含适合托盘和应用显示的多种尺寸。

## 下载与运行

**推荐安装版：下载 `FastWindowResizer-v1.0.0-win-x64-setup.exe`，双击并按简体中文向导安装。** 默认按当前用户安装，不需要管理员权限；自动创建开始菜单入口，可选桌面快捷方式，并支持从 Windows“已安装的应用”卸载。

也可下载免安装版 `FastWindowResizer-v1.0.0-win-x64.zip`，解压整个文件夹后运行 `FastWindowResizer.exe`。两种形式均随附运行时，无需安装 .NET。

安装包封装的是同一个 v1.0.0 应用版本。从便携版迁移时请先退出旧程序；若启用了旧版自启，在安装版中重新勾选“开机自启”。

在托盘区域找到蓝色窗口图标（可能位于隐藏图标菜单），右键后点击需要找回的窗口。需要自启时勾选菜单顶部的“开机自启”。

附件 `SHA256SUMS.txt` 同时提供安装包和便携压缩包的校验值。源码下载由 GitHub 自动提供；后续补充的安装脚本位于仓库 `main` 分支的 `installer/` 目录。

## 验证与边界

- 面向 Windows x64；在 Windows 11 上构建并验证。
- 发布前运行受控窗口、几何计算及自启配置检查；完整结果见仓库 `docs/VALIDATION.md`。
- 初版闲置工作集实测约 36.7 MiB，10 秒 CPU 采样增量为 0；实际占用依环境变化。
- 特殊全屏、无响应或权限更高的应用可能无法调整。
- 真实远程重连、混合 DPI 多屏、虚拟桌面切换和长期运行仍需使用中验证。
- 本版本未进行代码签名。
